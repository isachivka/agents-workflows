# Plan: serving agents' HTML reports

Spec: [2026-10-18-reports-design.md](../specs/2026-10-18-reports-design.md).
Each task: test first (fails), code, `npm test` and `npm run typecheck` green, one commit.

## Task 1 — `src/reports.ts`: store, serve, expire

Files: `src/reports.ts` (new), `test/reports.test.ts` (new).

- `class Reports({dir, url, maxBytes = 20 MB, keepMs = 30 days, now})`:
  - `publish(file): {url} | {error}` — the refusals of the spec; copy into `<dir>/<token>/<clean name>`.
  - `prune()` — removes token folders whose mtime is older than `keepMs`.
  - `handler(req, res)` — `GET`/`HEAD` `/r/<32 hex>/<name>` only, with the spec's headers; 404 otherwise.
- Tests: publish (path shape, cleaned name, URL), refusals, the served file and its headers for GET
  and HEAD, the 404 list (`/`, `/api/runs`, short token, `..`, `POST`), prune keeps new and drops old.

## Task 2 — flowd: `flow publish`, the listener, `flow say` links

Files: `src/daemon.ts`, `src/http.ts`, `src/cli.ts`, `src/main.ts`, `test/daemon-chat.test.ts`,
`test/http.test.ts`, `test/cli.test.ts`.

- `FlowdOptions.reports?: {dir, url}`; `Flowd.reports` built from it; `prune()` at init and daily
  (a timer, like the title timer).
- `Flowd.publish(file)`: refused `reports are not served: …` without the option.
- `say`: `.html`/`.htm` with reports on → publish, post `text + "\n" + url` with no file.
- `POST /api/publish {file}` (400 without a string `file`, 409 on refusal); `flow publish FILE`
  prints the URL (path made absolute).
- `main.ts`: with `FLOWS_REPORTS_URL` set, `reports: {dir: <state dir>/reports, url}` and a second
  server on `FLOWS_REPORTS_HOST:FLOWS_REPORTS_PORT` (default `0.0.0.0:7430`) with `reports.handler`;
  closed on stop.
- Tests: say with reports on posts the link and no file; a `.pdf` still goes as a file; without
  reports the `.html` goes as a file; `/api/publish` and `flow publish` print the URL; the refusal.
